# バルーンの記録

スマホ向けの個人用バルーンアート写真アルバム。作品名、制作日（不明なら空欄）、目的、メモ、複数の写真を登録・編集・削除でき、検索と JSON バックアップの保存・復元に対応します。

## 開発

依存パッケージのインストールは不要です。

```sh
cd /workspace/codex-practice
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで配信されたページを開きます。実際のスマホ利用には HTTPS での配信が別途必要です。まだ公開はしていません。

## 保存について

IndexedDB に写真の元データを含めて保存します。サーバーへの送信、ユーザー認証、端末間同期はありません。データは端末・ブラウザ・配信元ごとに独立しています。共有端末では同じブラウザを使う人が記録を閲覧できます。ブラウザデータ削除、端末故障や保存領域の消去に備えて、JSON バックアップを定期的に端末外にも保存してください。復元は既存データと統合し、同じ作品IDはバックアップで上書きします。容量不足時は保存エラーを表示します。

JPEG/PNG/WebP などブラウザが表示できる写真を推奨します。HEIC の表示対応はブラウザによって異なります。
